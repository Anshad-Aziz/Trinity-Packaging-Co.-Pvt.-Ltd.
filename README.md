# Trinity-Packaging-Co.-Pvt.-Ltd.
**A simple Python script that reads CSV file headers and generates short descriptive texts for each using a local open-source language model (FLAN-T5-small via Hugging Face Transformers). Outputs results to console and output.txt.**
#Requirements
- Python 3.8+
- transformers library: pip install transformers
- csv (built-in)
# Usage
- Run the script with the CSV file path as an argument:
  `python script.py your_file.csv`
